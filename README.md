# Student Grade Analyzer 

A NumPy project that analyzes 
student grades and generates 
detailed statistics.

## Features
Calculates average grade
Finds highest & lowest grade
Sorts grades high to low
Filters passed & failed students
Calculates pass percentage

## Technologies
Python | NumPy | Google Colab
